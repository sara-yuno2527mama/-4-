# AIキッチン秘書

料理は自分で、管理はAIと一緒に。

## 開発

```bash
npm run dev
```

http://localhost:3000 を開きます。

## いま動くこと

- ホーム: 日付＋家族写真、今日の朝夕、おすすめ、食べ忘れ、オイシックス日付、忘れないメモ
- 献立: 今日から14日、今週／来週、よく作る、パス、デザート
- 今ある: 家にあるものの一覧と使用期限の変更
- 追加: 買い物で追加／冷蔵庫から追加、オイシックス取込
- 設定: 家族写真、家庭・招待、LINE、オイシックス日付、検索サイト
- レシピ庫 `/recipes`: サイト型・インスタ型スクショ読取、完成写真（表紙）優先

色はオイシックス寄せの緑です。下タブは ホーム / 献立 / 今ある / 追加 / 設定。

## LINE通知

既存の前日20時（明日の朝夕）／当日7時（使い切り）に加え、使用期限未設定も当日7時に送ります。

## 画像の自動読取

レシピ写真の読み取りは、ホームの「サンプル写真で試す」または「写真から追加」から確認できます。`OPENAI_API_KEY` があれば実画像を読み取り、無い場合も課題提出用の読み取り結果が出ます。
